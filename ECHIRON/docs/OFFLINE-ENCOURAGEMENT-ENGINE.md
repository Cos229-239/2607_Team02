# Echiron Offline Encouragement Engine

Echiron's encouragement system is deliberately local and deterministic.

## Pipeline

1. Completion subject
2. Context classification
3. Signal detection
4. Principle scoring
5. Tone and depth selection
6. Repetition filtering
7. Encouragement display
8. Local feedback learning

## Inputs

- Task title
- Task details
- Task category
- Task priority
- Task age
- User role
- User goals
- Recent completion history
- Saved messages
- Dismissed messages
- Pinned principles
- Focus-session completions

## Outputs

- Immediate completion encouragement
- Recent wins
- Lessons earned
- Saved encouragements
- Personal principles
- Weekly reflection
- Today's encouragement

## Privacy

No encouragement content is sent to an AI service or remote server. Preferences, history, feedback, and reflections are stored with the rest of Echiron's local application data.

## Guardrails

The engine avoids:

- Shame
- Punitive streak language
- Exaggerated praise
- Mental-health diagnosis
- Religious assumptions
- Comparison with other people
- Dependence on an internet connection

Spiritual principles are opt-in and disabled by default.
